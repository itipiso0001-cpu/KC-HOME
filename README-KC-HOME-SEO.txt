KC HOME — SEO + Favicon update

Upload the files inside this package to the ROOT of the GitHub repository:
- index.html (replace the old index.html)
- favicon.ico
- favicon-48.png
- favicon-128.png
- apple-touch-icon.png
- robots.txt
- sitemap.xml

Important:
1. Extract this ZIP on your computer first; GitHub's Upload files page does not unpack a ZIP into the repository.
2. In GitHub, open https://github.com/itipiso0001-cpu/KC-HOME
3. Choose Add file > Upload files and select all seven files above together. Keep them in the repository root (same level as index.html).
4. Commit changes to main. Netlify should publish automatically if its main-branch auto publishing is still enabled.
5. Confirm the latest Production deploy succeeded before checking the live site.
6. In Google Search Console, run URL Inspection for https://www.kchome.online/ and click Request indexing. Then submit https://www.kchome.online/sitemap.xml under Sitemaps.

Google re-crawling can take days to several weeks, and neither indexing requests nor metadata guarantees a ranking for a specific query.
